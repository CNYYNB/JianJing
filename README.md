# 简境

一个干净、不打扰的 Windows 电脑清理工具。没有广告、没有弹窗推荐、不装全家桶，删东西前都能先看清楚要删什么，大部分删除 30 天内能找回。

## 下载

到右边的 **Releases** 下载 `简境-2.2.exe`，双击就能用（Windows 10/11 64 位）。

- 第一次运行会自动把自己装到 `%LocalAppData%\XinCleaner`，并在桌面和开始菜单放「简境」快捷方式。
- 不需要管理员权限，不需要另外装 .NET。
- 「设置」里可以手动检查更新，不会自己弹窗。

## 能做什么

| 页面 | 作用 |
|---|---|
| 概览 | 健康分、内存、磁盘、开机启动项数量，上次清理记录 |
| 扫描清理 | 浏览器缓存（不会退出登录）、临时文件、日志和错误报告、缩略图缓存、Windows 更新残留、微信缓存（默认不勾，不含聊天记录）、回收站。每一类都能点开预览，你点清理才会动 |
| 空间分析 | 磁盘地图、按类型统计、找大文件 |
| 重复文件 | 按内容比对（不看文件名），自动跳过系统和软件文件夹 |
| 软件管理 | 卸载软件并清理残留，对驱动、硬件厂商工具会标「别卸载」或「谨慎」 |
| 启动管理 | 开机启动项开关，标出建议保留的 |
| 隐私清理 | 最近打开的文件、Win+R 和地址栏记录、浏览器历史、缩略图、剪贴板 |
| 恢复中心 | 重复文件、卸载残留等删掉后 30 天内能找回 |
| 文件粉碎 | 把文件拖进来彻底删除，无法恢复 |
| 防护 | 检查防火墙、浏览器主页、hosts 文件是否被改，一键打开 Windows 安全中心 |
| 设置 | 定时清理（每天/每周/每月 03:00）、检查更新、卸载 |

## 安全设计

- 临时文件只删一天前的，更新残留只删 10 天前的。
- 不碰密钥、证书、密码库之类的文件（.pem、.key、.pfx、.kdbx 等）。
- 可以设置「不让简境碰的文件夹」。
- 所有清理都有记录，在「恢复中心」查看。

## 遇到问题怎么办

| 情况 | 处理 |
|---|---|
| 双击没反应 / 被杀毒软件拦了 | 新下载的程序没有数字签名，Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」 |
| 删错了东西 | 先去「恢复中心」找；回收站清空和文件粉碎是找不回的 |
| 某个软件清了缓存后变慢 | 缓存会自动重建，第一次打开慢一点是正常的 |
| 开机启动项关错了 | 回「启动管理」重新打开即可 |
| 卸载软件时提示「谨慎」 | 说明它可能是驱动、厂商工具或别的软件依赖的组件，不确定就别卸 |
| 想彻底卸载简境 | 设置 → 卸载，或在 Windows「应用和功能」里卸载 |
| 检查更新失败 | 网络问题或更新服务器暂时不可用，不影响使用；也可以直接到 Releases 下载新版覆盖 |

## 自己编译（可选）

需要 .NET 8 SDK：

```bash
cd src
dotnet publish -c Release
```

产物是一个单文件 `XinCleaner.exe`（自带运行时）。程序内部名字是 XinCleaner，界面显示「简境」。

自动更新地址在 `src/Updater.cs` 的 `Base`，仓库里是占位的 `https://jianjing.example.com/xinclean/`，自己发布的话改成你的地址，服务器上放 `version.json`（versionCode、versionName、notes、size、sha256）和 `latest.exe` 即可。
